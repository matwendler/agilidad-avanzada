# Developing Key Insights

## Descripción y propósito

Transformar datos crudos de investigación en **key insights** accionables mediante síntesis y comunicación. El foco no es acumular datos, sino destilar patrones en hallazgos "hugely powerful" que sirvan de referencia para todo el trabajo de diseño posterior.

Los key insights son el puente entre el descubrimiento y la ideación: anclan las decisiones en evidencia y abren el espacio de oportunidad.

## Fórmula: insight de tres niveles

> **"[Persona] hace [actividad] porque [necesidad], pero [fricción/obstáculo]."**

Ejemplo: *"Alan eats chocolate because it makes him feel safe, but it makes him fat."*

Esta estructura habilita atacar el desafío en tres niveles:

| Nivel | Pregunta de diseño |
|-------|--------------------|
| **Actividad / acción** | ¿Qué comportamientos alternativos satisfacen la misma necesidad? |
| **Necesidad / objetivo** | ¿Cuál es la causa raíz? ¿Qué otras soluciones existen? |
| **Restricción / fricción** | ¿Cómo eliminamos la consecuencia negativa? |

## Paso a paso

1. **Preparar e imprimir datos** — fotos, citas, videos, artefactos; armar el espacio e invitar participantes.
2. **Escribir insights iniciales** — documentar patrones y observaciones; equipos separados generan múltiples candidatos.
3. **Clusterizar, fusionar, priorizar** — agrupar similares, afinar el lenguaje, rankear por impacto en el cliente.
4. **Vincular a los datos** — conectar cada insight con evidencia vía sistema de indexado; sumar first-level constructs (fotos, citas, video).
5. **Encontrar gaps e iterar** — detectar datos faltantes, hacer trabajo de campo adicional, invitar a stakeholders a revisar.
6. **Follow-up** — fotografiar avances, escribir resúmenes, respaldar cada insight con **mínimo 2–3 piezas de evidencia**.

## Logística

| Aspecto | Detalle |
|---------|---------|
| Tiempo | 0,5 – 4 horas |
| Energía | Baja |
| Equipo | 1 mínimo; 2–3 investigadores óptimo |
| Participantes | 2–12 familiarizados con los datos (opcional) |
| Requisitos | Research wall o datos accesibles, personas, journey maps, papel, fibrones, cinta |
| Output | Key insights concretos y respaldados por evidencia |

## Notas críticas

- **Precisión:** insights vagos generan desafíos de diseño vagos. Formulación concreta y específica.
- **Rigor:** los insights requieren respaldo amplio; no apurar la formulación.
- **Calidad:** revisión por pares y workshops co-creativos para validar utilidad.
- **Profundidad:** técnica de **laddering** — encadenar insights con "because" para llegar a causas raíz y detectar gaps.
